# 名义尺寸与接口

下表汇总当前焊接版的名义值，用于理解设计和检查关联修改。制造尺寸、公差和局部轮廓应同时查阅CAD及工程图。历史审核发现的图模差异见[制造与核验状态](manufacturing-and-verification.md)。

## 坐标与箱体尺寸

模型以X表示箱体宽向，Y表示高度，Z表示前后方向：X0为箱体左侧基准位置，Y0为底面，后外面Z0，前外面Z=-308。侧板孔阵列另以U从前端起算。

| 项目 | 数值 mm | 范围与解释 |
| --- | --- | --- |
| 箱体基体长×宽×高 | 308 × 71.2 × 189 | 不含外伸件 |
| 板厚名义值 | 1.2 | 厚度验收与一般±0.5存在待澄清项 |
| 内部下 / 上平面 | Y1.2 / Y187.8 | 平板内部净高186.6 |
| 回折处最小内部净高 | 184.2 | 按现有说明及历史核验 |
| 四条回折宽 / 有效长 | 8 / 278 | 工艺展开需试折确认 |
| 含侧板基体宽 | 72.4 | 71.2 + 1.2，不含外伸安装件 |
| 含侧板全部已建零件包络 | 长319.3 × 宽84.9 × 高189 | 历史核验；含外伸件，不含未建螺钉 |
| 相同双箱相对平移 | X71.2 | 使用同一套单箱零件 |

```text

片内：4 + 24 + 4 = 32
```
